# Direction: NOTEBOOK MONO
Subject: Velo — Team BaCayKiem's product site. A 100% local, human-centric store & warehouse assistant for the Nordics (Netcompany IT Consultant Challenge 2026). Winner of the six-direction style pick.
One-line look: *a developer's notebook on cream paper — every surface a terminal readout, every claim a bordered card, one pastel-yellow pulse running through it.*

## Tokens (locked)
- Color (from `tokens.json`):
  - `--ink #000000` — terminal band, code windows, body-weight contrast moments
  - `--ink-soft #3A3A3A` — ALL text and every border (charcoal ink, never pure black on paper)
  - `--paper #FFFFFF` — card surfaces and nav/footer bands
  - `--yellow #FFF9A3` — PRIMARY tint: marquee band, highlight blocks behind keywords, kicker chip, section washes, hover feedback
  - `--yellow-deep #FBDD65` — SECONDARY accent, rationed: CTA fills, the "2 REFILLS DUE!" badge, live-signal marks, the quote card
  - `--cream #FFFDD6` — page canvas
- Type: Space Mono 400/700, everywhere — headlines, body, buttons, labels. Uppercase for display, sentence case for reading. `letter-spacing: .02em` opens the mono rhythm.
- Layout: centered hero stack over a signature console; alternating full-bleed bands (cream → pastel → black → cream); 2px charcoal borders; square everything.
- Signature element: the **pastel pulse band** — a full-bleed `--yellow` marquee strip (charcoal type, 2px charcoal rules) carrying the four store-zone verbs, plus the ruled task/task-queue language that repeats through the page. Everything else stays quiet.
- Anti-slop contract: border-radius 0 everywhere, no drop shadows (borders are the elevation), no gradients, no glassmorphism, no emoji in UI copy.

## This is NOT
- **Not** a rounded SaaS template — the rounded-card + soft-shadow kit is the #1 AI tell; here every corner is 90° and every elevation is a 2px line.
- **Not** a dark-mode hacker site — the world is cream paper; black appears once (the sovereignty band) for deliberate contrast.
- **Not** yellow soup — pastel carries the brand fields, the saturated deep yellow appears only where something ACTS: a button, a live badge, a quote.
